# Use Case: Изменение количества товара

## Описание
Позволяет пользователю изменять количество товара и автоматически обновлять его статус на основе нового значения.

## Актеры
- Пользователь (администратор/менеджер)

## Триггер
Пользователь изменяет количество товара в системе управления.

## Предусловия
1. Пользователь авторизован в системе
2. Товар существует в системе
3. Товар выбран в таблице

## Основной поток событий
1. Пользователь выбирает товар из таблицы
2. Система заполняет поля формы данными выбранного товара
3. Пользователь изменяет значение в поле "Количество"
4. Пользователь нажимает кнопку "Изменить"
5. Система валидирует введенные данные:
   - Проверяет, что количество - целое число
   - Проверяет, что количество ≥ 0
6. Система сохраняет изменения в текущем хранилище (RAM/MySQL/PostgreSQL)
7. Система обновляет данные в таблице
8. Система очищает поля формы

## Альтернативные потоки

### A1: Некорректный ввод количества
1. Пользователь вводит нечисловое значение
2. Система отображает ошибку: "Количество должно быть числом"
3. Пользователь исправляет данные
4. Возврат к шагу 5 основного потока

### A2: Отрицательное количество
1. Пользователь вводит отрицательное число
2. Система отображает ошибку: "Количество не может быть отрицательным"
3. Пользователь исправляет данные
4. Возврат к шагу 5 основного потока

## Постусловия
- Количество товара обновлено в системе
- Изменения сохранены в выбранном хранилище
- Интерфейс синхронизирован с актуальными данными
